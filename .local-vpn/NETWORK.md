# Сеть гостиницы и локальный VPN

## Назначение

Модуль обеспечивает доступ из Codex/Windows к физической локальной сети гостиницы по OpenVPN. Он предназначен для быстрого открытия роутера, трёх камер и принтера по запросу пользователя.

## VPN

- OpenVPN: `C:\Program Files\OpenVPN\bin\openvpn.exe`
- исходный профиль на этом компьютере: `C:\Users\Admin\Downloads\MMM_PRO_HHH.ovpn`
- точная зашифрованная копия в проекте: `hotel-profile.ovpn.dpapi`
- SHA-256 открытого профиля: `BC7742537189F4A32B4BE2D77CF453528D81BDAEF7CCAA89D66F5CD90572E430`
- размер открытого профиля на момент копирования: 10026 байт
- защита копии: Windows DPAPI, область `CurrentUser`
- строка дополнительной энтропии: `sova-mira-site/hotel-vpn-profile/v1`
- адрес VPN-клиента при последней проверке: `192.168.224.2`
- VPN-шлюз при последней проверке: `192.168.224.1`
- локальная сеть гостиницы: `192.168.0.0/24`
- маршрут: `192.168.0.0 mask 255.255.255.0 vpn_gateway metric 1`

Профиль сервера присылает `redirect-gateway def1` и DNS `8.8.8.8`. Модуль намеренно игнорирует обе директивы через `pull-filter`, чтобы через гостиницу шёл только трафик к `192.168.0.0/24`. Маршруты `0.0.0.0/1` и `128.0.0.0/1` считаются ошибочным состоянием.

## Сертификат веб-интерфейса Pritunl

- адрес: `https://192.168.0.183/login`
- хранилище Windows: `CurrentUser\\Root`
- отпечаток: `764F474F583E7471CD0967FB0208427435C623C0`
- срок действия: до 20 мая 2035 года
- сертификат самоподписанный и не содержит CN/SAN для `192.168.0.183`

18 октября 2026 года сертификат был добавлен в доверенные для текущего пользователя по прямому разрешению владельца. Это устранило `ERR_CERT_AUTHORITY_INVALID`, но браузер продолжил блокировать страницу с `ERR_CERT_COMMON_NAME_INVALID`, потому что имя/IP отсутствует в сертификате. Для окончательного исправления на Pritunl необходимо выпустить сертификат с корректным SAN.

Команда удаления доверия при необходимости:

```powershell
Remove-Item 'Cert:\\CurrentUser\\Root\\764F474F583E7471CD0967FB0208427435C623C0'
```

## Быстрый сценарий для ассистента

```powershell
$vpn = 'C:\16 GB\NEW\WEB_sova-mira-site\.local-vpn\hotel-vpn.ps1'
& $vpn start
& $vpn url router
& $vpn url camera1
& $vpn url camera2
& $vpn url camera3
& $vpn url printer
```

Полученный URL следует открывать во внутреннем браузере Codex. VPN оставляют подключённым, пока пользователю нужны открытые вкладки. После завершения работы выполняют `& $vpn stop`.
