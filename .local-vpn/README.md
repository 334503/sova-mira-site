# Локальный доступ к сети гостиницы

Этот каталог содержит переносимую часть модуля доступа и виден Git как обычная часть проекта.
Зашифрованная копия VPN-профиля `hotel-profile.ovpn.dpapi` является локальным credential-файлом и исключена из Git.
Она защищена Windows DPAPI и привязана к текущей учётной записи Windows, поэтому при переносе компьютера профиль нужно подготовить заново или перенести отдельно безопасным способом.
При подключении скрипт проверяет SHA-256, расшифровывает профиль во временный каталог `%LOCALAPPDATA%\SovaMiraHotelVpn` и удаляет временную копию при отключении.

Подключение работает в режиме split tunnel: через VPN направляется только сеть гостиницы `192.168.0.0/24`.
Обычный интернет и DNS компьютера не должны перенаправляться через гостиницу.

## Команды

Запускать из PowerShell:

```powershell
& '.\.local-vpn\hotel-vpn.ps1' start
& '.\.local-vpn\hotel-vpn.ps1' status
& '.\.local-vpn\hotel-vpn.ps1' list
& '.\.local-vpn\hotel-vpn.ps1' test
& '.\.local-vpn\hotel-vpn.ps1' url camera1
& '.\.local-vpn\hotel-vpn.ps1' open router
& '.\.local-vpn\hotel-vpn.ps1' stop
```

При `start` и `stop` Windows показывает стандартное подтверждение UAC, потому что OpenVPN и таблица маршрутизации требуют прав администратора.

## Псевдонимы

- `router`, `роутер` — TP-Link, настройки WAN (`192.168.0.1`)
- `camera1`, `cam108`, `108`, `камера1` — камера `192.168.0.108`
- `camera2`, `cam135`, `135`, `камера2` — камера `192.168.0.135`
- `camera3`, `cam162`, `162`, `камера3` — камера `192.168.0.162`
- `printer`, `xerox`, `138`, `принтер`, `ксерокс` — Xerox `192.168.0.138`

Для запроса «открой в браузере роутер/камеру/принтер» ассистент должен:

1. выполнить `hotel-vpn.ps1 start`;
2. получить адрес через `hotel-vpn.ps1 url <псевдоним>`;
3. открыть адрес во внутреннем браузере Codex;
4. не отключать VPN, пока вкладка нужна пользователю.

Полная схема сети и технические детали находятся в `NETWORK.md`. Исходный открытый профиль по-прежнему находится по пути, записанному в `config.local.json`, но для работы модуля используется сохранённая зашифрованная копия.
